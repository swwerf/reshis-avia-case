# ✈️ Сервис динамического ценообразования «Решись Авиа»

Веб-приложение для прогнозирования спроса и подбора оптимальных цен на авиабилеты на основе машинного обучения и квантильного анализа.

## 🛠 Архитектура и стек технологий

Проект реализован в рамках **Варианта С (Веб-страница с Backend-составляющей)** и включает **все 4 дополнительные функции** из технического задания:

*   **Backend:** `Python 3`, `FastAPI`, `Uvicorn` — асинхронный высокопроизводительный REST API.
*   **База данных:** `SQLite3` (встроенная реляционная БД) — хранение учетных записей пользователей и токенов сессий.
*   **Безопасность:** Хэширование паролей алгоритмом `SHA-256`, авторизация через `Bearer Token`.
*   **Обработка данных:** `pandas`, `numpy` — работа с прогнозами и матрицами маршрутов.
*   **Frontend:** `HTML5`, `CSS3`, `Bootstrap 5` (адаптивный UI), нативный `JavaScript (Fetch API)`.
*   **Визуализация:** `Chart.js` — интерактивный график распределения спроса по квантилям с линией вместимости борта.

## 🚀 Реализованный функционал

1. **Базовый калькулятор спроса (Вариант С):**
   * Выбор маршрута, даты вылета (июнь 2026 г.) и цены билета.
   * Расчет ожидаемого спроса и фактических продаж с учетом чувствительности к цене (`price_sensitivity`) и физической вместимости самолета (`seats`) по формуле из регламента:
     $$\text{желают} = \text{demand}_{0.5} - \text{sensitivity} \times (\text{цена} - \text{base\_price})$$
     $$\text{купят} = \min(\text{seats}, \max(0, \text{желают}))$$
2. **Дополнительная функция 1 (График распределения спроса):**
   * Интерактивная кривая продаж по всем 9 сценариям (квантили от 0.1 до 0.9).
   * Отметка предельной вместимости самолета (`seats`) пунктирной линией, наглядно демонстрирующая выход на "полку" при дефиците кресел.
3. **Дополнительная функция 2 и 3 (Регистрация и Авторизация):**
   * Полноценная система аутентификации.
   * Доступ к расчетным эндпоинтам защищен зависимостями (`Depends`) и выдачей уникальных токенов.
4. **Дополнительная функция 4 (Размещение на хостинге):**
   * Проект полностью подготовлен к облачному деплою и контейнеризации.
